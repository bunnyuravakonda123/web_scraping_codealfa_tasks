# Web Scraping Project Report

## 1. Introduction

The objective of this project was to collect information from a public website using Python web-scraping techniques.

## 2. Tools and Technologies

* Python
* Requests
* BeautifulSoup
* Pandas
* Visual Studio Code

## 3. Website Used

Books to Scrape, a practice website designed for learning web scraping.

## 4. Data Collected

I collected the following information from the first page of the website:

* Book titles
* Book prices

The collected information was saved in a CSV file named `scraped_books.csv`.

## 5. Implementation

I used the Requests library to retrieve the webpage and BeautifulSoup to extract book titles and prices from its HTML structure. I then used Pandas to organize the collected information and save it as a CSV file.

## 6. Conclusion

This project helped me understand the basics of web scraping, HTML parsing, and storing collected data in a structured CSV file.
